# Один Docker-образ: бэкенд отдаёт и API, и собранный фронтенд

Production-сборка — один процесс Fastify: он обслуживает `/api/*`, раздаёт `frontend/dist` и отвечает `index.html` на остальные переходы по страницам, чтобы работали адреса клиентского роутера. Так приложение запускается одним контейнером на одном порту из `PORT`, подходит для Render и подобных платформ и не требует CORS или отдельного сервера статики. Фронтенд и бэкенд из-за этого выкатываются только вместе.
