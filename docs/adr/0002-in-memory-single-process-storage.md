# Записи хранятся в памяти одного процесса

Типы встреч и встречи живут в памяти процесса Node.js, без базы данных. Запрет пересекающихся встреч, включая одновременные запросы на одно время, держится на том, что проверка пересечения и сохранение выполняются синхронно, без `await` между ними, в единственном процессе. Задание не требует сохранять данные после перезапуска, а база ради одного правила усложнила бы запуск и деплой.

## Consequences

- После перезапуска все записи пропадают; демо-типы встреч создаются заново.
- Сервис нельзя масштабировать на несколько экземпляров: каждый держал бы свои записи, и запрет пересечений перестал бы работать. При переходе на базу правило нужно перенести в неё (ограничение исключения или транзакция с блокировкой).
